# Jikimi

[English](README.md) · **한국어**

Jikimi(지키미)는 AI 서비스를 활용해 코드의 보안 문제를 찾고 판단을 돕는 보안 에이전트입니다. 개발자 PC의 에이전트가 코드를 검사하고, AI가 오탐 여부와 고치는 방법을 제안하면 담당자가 조직의 정책에 따라 결정하고, 조치한 뒤 다시 확인합니다. [한비엣테크](https://hanvietech.com)가 개발하고 있습니다.

> **출시를 준비하고 있는 제품입니다.** 이 저장소는 제품 소개와 사용 방법을 담은 공개 문서이며, 제품 소스코드는 공개하지 않습니다. 소개된 기능과 구성은 출시 과정에서 달라질 수 있습니다.

**[데모 화면 보기](https://demo.hanvietech.com/)** · 홈, 프로젝트, 발견 항목 상세, 검토함, 에이전트 설치 화면을 샘플 데이터로 직접 눌러 볼 수 있습니다. 실제 고객 데이터는 없습니다.

## 서비스 흐름

1. **보안 검사**: 개발자 PC의 에이전트가 코드와 사용하는 오픈소스에서 보안상 문제가 될 수 있는 부분을 찾습니다.
2. **AI·사람의 검토**: AI가 결과마다 오탐 여부와 고치는 방법을 제안하고, 담당자가 확인합니다.
3. **정책 판단**: 조직이 정한 보안 정책에 따라 통과·보류·조치 여부를 결정합니다.
4. **조치·재검사**: 조치한 결과를 다시 검사해 문제가 해결됐는지 확인합니다. 해결되지 않은 문제는 다시 검사 흐름으로 이어집니다.

## 왜 Jikimi인가

- **네 가지 위험을 한 번에**: 민감정보 · 라이브러리 · 시큐어코드 · 라이센스를 한 번의 검사로 찾고 하나의 기준으로 정리합니다.
- **저장소는 개발자 PC를 떠나지 않습니다**: 검사는 개발자 PC에서 돌고 결과와 필요한 코드 조각만 보냅니다. 민감정보는 PC에서 가린 뒤 보냅니다.
- **AI는 제안하고 사람이 결정합니다**: AI가 오탐 여부와 고치는 방법을 근거와 함께 제안하고, 담당자가 검토함에서 결정합니다. 모든 결정은 이력에 남습니다.
- **클라우드로도, 사내망에도**: 클라우드 서비스로 쓰거나, 인터넷이 막힌 사내망에 설치하고 사내 LLM을 연결할 수 있습니다.

## 주요 기능

### 결과 보기

- **오늘 할 일**: 첫 화면에서 검토를 기다리는 항목, 실제로 동작하는 민감정보, 버전만 올리면 해결되는 라이브러리 취약점, 검사에 문제가 있는 프로젝트를 먼저 보여 줍니다.
- **같은 문제는 한 번만**: 프로젝트별·범주별 미해결 항목을 보여 주고, 같은 문제는 한 번만 셉니다. 신규·재발·해결 여부는 검사마다 이어서 추적합니다.
- **왜 위험한지와 고치는 방법**: 항목마다 위험한 이유와 고치는 방법을 한국어로 설명합니다. 라이브러리 취약점은 고칠 버전을, 라이센스는 필요한 검토를 함께 보여 줍니다.
- **찾기와 거르기**: 프로젝트·패키지·CVE로 찾고, 범주·심각도·처분·담당자·기간 같은 조건으로 거릅니다.

### 검토와 결정

- **AI 판단**: AI가 항목을 정탐·오탐·검토 필요로 추정하고, 근거와 코드에 맞춘 제안 패치를 함께 보여 줍니다. AI 판단은 제안일 뿐 처분을 바꾸지 않습니다.
- **검토함**: 사람이 결정해야 할 항목만 모읍니다. AI가 오탐으로 추정한 항목, 처분한 뒤 코드가 바뀐 항목, 위험 수용 기한이 지난 항목을 나눠 보여 줍니다.
- **처분과 이력**: 처리 중 · 오탐 · 위험 수용(기한 필수)을 사유와 함께 기록하고, 담당자와 메모를 남깁니다. 여러 항목을 한 번에 처리하고 바로 되돌릴 수 있으며, 모든 변경은 항목 이력에 남습니다.
- **예외 규칙**: 반복되는 항목은 경로나 범위를 정해 앞으로도 같은 처분이 적용되게 합니다.

### 운영

- **역할과 범위**: 관리자 · 멤버 · 열람자 역할과 프로젝트 범위를 정하고, 일회용 초대 링크로 담당자를 추가합니다.
- **검사 운영**: 검사 이력, 실패와 설치 누락, 예약 검사, 연결된 PC를 한곳에서 관리합니다.
- **설치 명령 한 줄**: 화면에서 만든 명령 한 줄로 개발자 PC에 에이전트를 설치합니다. 에이전트는 새 버전을 스스로 확인해 갱신합니다.

## 사용 방법

### 보안 담당자

1. **계정 개통**: 한비엣테크가 조직의 계정을 열어 드리면, 안내받은 링크에서 비밀번호를 정하고 로그인합니다.
2. **담당자 초대**: 함께 일할 담당자가 있으면 **설정 → 사용자 · 역할**에서 역할과 프로젝트 범위를 정해 초대 링크를 전달합니다.
3. **설치 명령 전달**: **검사 운영 → 에이전트**에서 PC 이름을 넣고 설치 명령을 만들어 개발자에게 전달합니다.
4. **결과 확인**: 홈의 오늘 할 일과 프로젝트별 결과를 보고, 항목을 열어 위치·위험한 이유·고치는 방법·AI 판단을 확인합니다.
5. **검토와 결정**: 검토함에서 AI 제안과 다시 볼 항목을 결정합니다.

### 개발자

보안 담당자에게 받은 설치 명령을 터미널에 붙여 넣어 실행합니다. 검사 준비와 자동 시작까지 함께 끝나며, 접속 정보를 따로 입력하지 않습니다. 그다음 프로젝트 폴더에서 검사합니다.

```sh
jikimi scan .   # 검사 실행
```

검사가 끝나면 결과는 보안 담당자의 화면에 나타납니다. 지원 환경은 macOS부터 시작하며, Windows는 이후 지원할 예정입니다.
