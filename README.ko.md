# AI 코드보안 지킴이

[English](README.md) · **한국어**

코드의 보안 문제를 찾고, AI와 사람이 함께 검토하고, 조직의 정책에 따라 판단하고, 조치한 뒤 다시 확인하는 과정을 하나로 잇는 솔루션입니다. [한비엣테크](https://hanvietech.com)가 개발하고 있습니다.

> **개발 중인 제품입니다.** 이 저장소는 제품 소개와 사용 방법을 담은 공개 문서이며, 제품 소스코드는 공개하지 않습니다. 소개된 기능과 구성은 개발 과정에서 달라질 수 있습니다.

**[데모 화면 보기](https://demo.hanvietech.com/)** · 샘플 데이터로 만든 결과 화면이며 실제 고객 데이터는 없습니다.

## 서비스 흐름

1. **보안 검사**: 코드와 사용하는 오픈소스에서 보안상 문제가 될 수 있는 부분을 찾습니다.
2. **AI·사람의 검토**: AI가 결과를 정리해 설명하고, 담당자가 확인합니다.
3. **정책 판단**: 조직이 정한 보안 정책에 따라 통과·보류·조치 여부를 결정합니다.
4. **조치·재검사**: 조치한 결과를 다시 검사해 문제가 해결됐는지 확인합니다. 해결되지 않은 문제는 다시 검사 흐름으로 이어집니다.

## 주요 기능

- **통합 보안 검사**: 소스코드, 오픈소스 구성요소, 비밀값, 라이선스를 한 번의 검사로 살펴보고 결과를 하나의 기준으로 정리합니다.
- **한눈에 보는 결과**: 프로젝트별·범주별 항목 수를 보여 주고, 같은 문제는 한 번만 셉니다. 신규·재발·해결 여부도 이어서 보여 줍니다.
- **왜 위험한지와 고치는 방법**: 항목마다 위험한 이유와 고치는 방법을 한국어로 설명합니다.
- **AI 검토**: AI가 항목을 정탐·오탐·검토 필요로 판정하고, 근거와 수정 방향을 함께 제시합니다. AI 검토에는 Anthropic의 Claude를 사용합니다.
- **사람이 최종 확인**: AI 판정은 제안입니다. 담당자가 확인한 항목만 오탐으로 처리되어 집계에서 빠집니다.

## 사용 방법

### 보안 담당자

1. **계정 개통**: 한비엣테크가 조직의 계정을 열어 드리면, 안내받은 링크에서 비밀번호를 정하고 로그인합니다.
2. **에이전트 전달**: 화면에서 에이전트 다운로드 링크를 만들어 개발자에게 전달합니다.
3. **결과 확인**: 대시보드에서 프로젝트별 결과를 보고, 항목을 열어 위치·위험한 이유·고치는 방법을 확인합니다.
4. **AI 판정 확인**: AI가 오탐으로 추정한 항목을 근거와 함께 보고 한 번에 확인합니다.

### 개발자

보안 담당자에게 받은 묶음을 풀고, 프로젝트 루트에서 아래 순서로 실행합니다. 접속 정보는 묶음에 들어 있어 따로 입력하지 않습니다.

```sh
./jikimi install --yes   # 검사 준비
./jikimi scan .          # 검사 실행
```

검사가 끝나면 결과는 보안 담당자의 대시보드에 나타납니다. 지원 환경은 macOS부터 시작하며, Windows는 이후 지원할 예정입니다.
